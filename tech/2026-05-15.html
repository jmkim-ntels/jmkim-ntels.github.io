1. Meta, WhatsApp에 완전 비공개형 ‘Incognito Chat with Meta AI’ 도입

핵심 요약

Meta는 5월 13일 WhatsApp과 Meta AI 앱에 ‘Incognito Chat with Meta AI’를 도입한다고 발표했습니다. 회사 설명에 따르면 이 기능은 WhatsApp의 Private Processing 기술 위에서 동작하며, Meta조차 대화 내용을 볼 수 없는 구조를 목표로 합니다. 대화는 기본적으로 저장되지 않고, 임시 세션처럼 사라지는 방식으로 설계됐습니다. Meta는 민감한 질문이나 사적인 상담성 대화에서도 안심하고 AI를 쓰게 만드는 것이 핵심 의도라고 밝혔습니다.

배경·업계 영향

메신저 기반 AI가 널리 쓰이려면 답변 품질만큼이나 데이터 처리 신뢰가 중요합니다. 이번 발표는 메타가 AI 경쟁에서 단순 기능 추가보다 프라이버시 구조 자체를 차별화 포인트로 밀고 있다는 신호입니다. 다른 메신저·소셜 플랫폼도 AI 대화의 처리 방식과 저장 정책을 더 투명하게 설명해야 하는 압박을 받을 가능성이 큽니다.

왜 중요한지: 메신저 AI의 다음 승부처는 성능만이 아니라 “누가 이 대화를 볼 수 있느냐”에 대한 신뢰입니다.

Meta Newsroom, Introducing a Completely Private Way to Chat With AI

2. Anthropic, ‘Claude for Small Business’로 중소사업자 자동화 패키지 공개

핵심 요약

Anthropic은 5월 13일 ‘Claude for Small Business’를 발표하며 중소사업자용 커넥터·워크플로 패키지를 내놨습니다. QuickBooks, PayPal, HubSpot, Canva, Docusign, Google Workspace, Microsoft 365 같은 도구에 Claude를 연결해 급여 계획, 월마감, 인보이스 추적, 마케팅 캠페인 준비 등을 돕는 방식입니다. 회사는 15개의 ready-to-run 워크플로와 15개의 스킬을 제공한다고 설명했습니다. 또한 실제 송금·발송·지급 전에는 사용자가 승인하도록 설계해 통제권을 유지한다고 강조했습니다.

배경·업계 영향

그동안 SMB용 AI는 범용 채팅 체험에 머무는 경우가 많았는데, 이번에는 회계·운영·영업툴 안으로 직접 들어가는 패키지형 자동화에 더 가깝습니다. 이는 엔터프라이즈에서 검증된 커넥터 전략이 소규모 사업자 시장으로 내려오기 시작했다는 뜻이기도 합니다. 앞으로는 모델 성능보다 실제 업무 소프트웨어와 얼마나 깊게 연결되느냐가 SMB AI 도입 속도를 좌우할 가능성이 큽니다.

왜 중요한지: 중소기업 시장에서 AI의 진짜 경쟁은 멋진 데모가 아니라 밤늦게 남는 잡무를 실제로 줄여주느냐입니다.

Anthropic, Introducing Claude for Small Business

3. OpenAI, 실시간 음성용 신규 API 모델 3종 공개

핵심 요약

OpenAI는 5월 7일 API용 신규 오디오 모델로 GPT‑Realtime‑2, GPT‑Realtime‑Translate, GPT‑Realtime‑Whisper를 발표했습니다. GPT‑Realtime‑2는 GPT‑5급 추론을 실시간 음성 대화에 접목해 더 어려운 요청 처리, 맥락 유지, 툴 호출을 강화한 것이 핵심입니다. 번역 모델은 70개 이상 입력 언어와 13개 출력 언어를 지원하며, Whisper 기반 스트리밍 전사는 회의 기록·콜센터·실시간 자막 같은 사용처를 겨냥합니다. OpenAI는 컨텍스트 윈도를 32K에서 128K로 확대해 더 긴 에이전트형 대화를 지원한다고 설명했습니다.

배경·업계 영향

이 발표는 음성이 단순 입출력 채널을 넘어, AI가 실제로 일을 처리하는 핵심 인터페이스로 올라오고 있음을 보여줍니다. 특히 번역·전사·도구 호출이 하나의 실시간 스택 안에서 정리되면 고객지원, 여행, 현장 업무 같은 분야의 음성 자동화 도입이 빨라질 수 있습니다. 음성 AI 시장도 결국 정확도뿐 아니라 지연시간, 제어 가능성, 운영 편의성 경쟁으로 재편될 가능성이 큽니다.

왜 중요한지: 실시간 음성 AI가 똑똑해질수록 챗봇은 화면 속 기능이 아니라 전화·회의·현장 업무의 인터페이스가 됩니다.

4. Google Cloud, ‘Gemini Enterprise Agent Platform’으로 Vertex AI를 에이전트 중심으로 재편

핵심 요약

Google Cloud는 4월 23일 Gemini Enterprise Agent Platform을 발표하며 Vertex AI를 에이전트 구축·운영·거버넌스 중심 플랫폼으로 확장한다고 밝혔습니다. 회사 설명에 따르면 이 플랫폼은 모델 선택, 모델 개발, 에이전트 개발 기능에 더해 통합, DevOps, 오케스트레이션, 보안 기능을 함께 제공합니다. 또한 Model Garden을 통해 200개 이상 모델에 접근할 수 있고, Gemini 계열뿐 아니라 서드파티 모델도 함께 활용할 수 있다고 설명했습니다. Google은 앞으로 Vertex AI의 진화가 별도 서비스가 아니라 Agent Platform을 통해 이뤄진다고 못 박았습니다.

배경·업계 영향

이 발표는 Google Cloud의 AI 메시지가 ‘좋은 모델을 제공하는 클라우드’에서 ‘기업용 에이전트 운영체계’로 이동하고 있다는 선언에 가깝습니다. 기업 입장에서는 이제 모델 하나보다 장기 상태 유지, 보안, 배포, 관찰 가능성 같은 운영 요소가 더 중요한 구매 기준이 되고 있습니다. 경쟁 클라우드도 에이전트 플랫폼 메시지를 더 제품화된 운영 도구로 구체화해야 할 가능성이 큽니다.

왜 중요한지: 기업 AI의 실전 경쟁은 모델 단품이 아니라 에이전트를 안전하게 굴리는 전체 스택에서 벌어집니다.

Google Cloud Blog, Introducing Gemini Enterprise Agent Platform

5. AWS, Amazon Bedrock에 OpenAI 모델·Codex·Managed Agents 제한적 프리뷰 공개

핵심 요약

AWS는 4월 28일 ‘What’s Next with AWS 2026’ 발표와 함께 Amazon Bedrock에서 최신 OpenAI 모델, Codex, 그리고 OpenAI 기반 Managed Agents를 제한적 프리뷰로 제공한다고 발표했습니다. AWS 설명에 따르면 고객은 기존 Bedrock API와 보안·거버넌스 체계를 그대로 쓰면서 OpenAI 모델을 사용할 수 있습니다. Codex는 AWS 자격 증명과 Bedrock 인프라 안에서 동작하며 CLI, 데스크톱 앱, VS Code 확장과 연결됩니다. Managed Agents는 각 에이전트의 고유 ID, 실행 로그, 고객 환경 내 실행을 강조하며 기업 운영 요구를 겨냥했습니다.

배경·업계 영향

AWS는 자체 모델 경쟁보다 다양한 프런티어 모델을 자사 운영체계 안에서 안전하게 쓰게 하는 전략을 강화하고 있습니다. 특히 OpenAI 모델을 Bedrock 안으로 끌어들인 것은 멀티모델 선택권이 클라우드 경쟁력의 핵심이라는 점을 분명히 보여줍니다. 앞으로 클라우드 사업자들은 “우리 모델”보다 “원하는 모델을 우리 거버넌스 안에서 쓸 수 있느냐”로 더 자주 평가받을 가능성이 큽니다.

왜 중요한지: 클라우드 전쟁은 점점 “누구 모델이냐”보다 “누구 운영환경에서 믿고 굴릴 수 있느냐”로 바뀌고 있습니다.
