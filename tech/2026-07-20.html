1. OpenAI, GPT-5.6을 Microsoft 365 Copilot의 기본 선호 모델로 확대

핵심 요약

OpenAI는 2026년 7월 9일 GPT-5.6이 Microsoft 365 Copilot의 새로운 preferred model이 된다고 발표했습니다. 적용 범위는 Word, Excel, PowerPoint, Chat, Cowork까지 포함되며, 일상적인 생산성 앱에서 더 적은 프롬프트로 더 완성도 높은 결과물을 내는 방향이 강조됐습니다. OpenAI는 GPT-5.6이 더 나은 성능당 비용과 복잡한 작업 처리 능력을 제공한다고 설명했습니다. Microsoft도 공식 인용문에서 문서 작성, 데이터 분석, 프레젠테이션 제작, 협업 전반의 품질 향상을 기대한다고 밝혔습니다.

배경·업계 영향

이 발표는 프런티어 모델 경쟁이 API 데모를 넘어 오피스 스위트의 기본 작업 흐름 안으로 깊숙이 들어갔다는 신호입니다. 기업 입장에서는 새로운 AI 도구를 따로 도입하기보다 기존 업무 앱 안에서 더 강한 모델을 바로 쓰는 편이 전환 비용이 낮습니다. 결국 모델 사업자는 성능뿐 아니라 대형 소프트웨어 플랫폼의 기본값이 되는 유통력을 확보해야 더 강해집니다.

왜 중요한지: 생성형 AI가 별도 실험도구가 아니라 매일 쓰는 업무 소프트웨어의 기본 엔진이 되고 있습니다.

2. Google, Gemini 3.5 Flash에 computer use를 기본 도구로 통합

핵심 요약

Google은 2026년 6월 24일 Gemini 3.5 Flash에 computer use 기능을 내장 도구로 넣었다고 발표했습니다. 이전에는 별도 Gemini 2.5 computer use 모델이 맡던 역할이 이제 메인 Flash 모델 안으로 통합돼, 브라우저·모바일·데스크톱 환경을 오가며 행동하는 에이전트를 더 쉽게 만들 수 있게 됐습니다. Google은 Gemini API와 Gemini Enterprise Agent Platform을 통해 개발자와 기업이 이 기능을 바로 사용할 수 있다고 밝혔습니다. 동시에 민감하거나 되돌리기 어려운 작업에 사용자 확인을 요구하고, 간접 프롬프트 인젝션이 감지되면 작업을 멈추는 보호 장치도 함께 공개했습니다.

배경·업계 영향

모델이 텍스트를 잘 쓰는 수준을 넘어 실제 화면을 보고 조작하는 능력은 에이전트 제품 경쟁의 핵심으로 떠오르고 있습니다. Flash급 모델에 이런 기능이 기본 탑재되면 비용과 속도 측면에서 대규모 배포 가능성이 커집니다. 이는 에이전트 시장이 고가 프리미엄 모델 중심에서 더 넓은 개발자 생태계로 확산될 수 있음을 뜻합니다.

왜 중요한지: 저지연 모델에 행동 능력이 붙으면서 에이전트 자동화가 더 현실적인 제품 범주로 이동하고 있습니다.

Google Blog, Introducing computer use in Gemini 3.5 Flash

3. Meta, Muse Spark 1.1과 Meta Model API 프리뷰로 에이전트 경쟁에 재가속

핵심 요약

Meta는 2026년 7월 9일 Muse Spark 1.1을 공개하면서 새로운 Meta Model API 공개 프리뷰도 함께 시작했습니다. 회사 설명에 따르면 Muse Spark 1.1은 멀티모달 추론, 컴퓨터 사용, 코딩, 긴 컨텍스트 관리에 강점을 두고 있으며, agentic task를 위한 상위 모델로 포지셔닝됩니다. Meta는 이 모델이 Meta AI 앱의 Thinking 모드로도 제공되고, 개발자는 새 API를 통해 직접 접근할 수 있다고 밝혔습니다. 특히 여러 앱과 서비스에 걸친 작업 계획과 오케스트레이션 성능을 강조했습니다.

배경·업계 영향

Meta는 오픈 모델 생태계에 강점을 가져왔지만, 이번에는 자체 앱과 개발자 API를 동시에 밀며 더 직접적인 플랫폼 경쟁 구도로 들어가고 있습니다. 단순 챗봇이 아니라 장기 컨텍스트와 멀티앱 실행을 내세우는 점은 OpenAI·Google과 같은 에이전트 전선에서 정면 승부하겠다는 의미에 가깝습니다. 개발자 관점에서는 선택지가 늘어나는 반면, 각 벤더별 에이전트 스택 차별화도 더 심해질 가능성이 큽니다.

왜 중요한지: Meta도 이제 연구 공개를 넘어 실행형 에이전트 플랫폼 사업자로 무게중심을 옮기고 있습니다.

Meta AI, Introducing Muse Spark 1.1

4. Microsoft, Discovery를 정식 출시하며 과학 연구용 에이전트 플랫폼을 전면 배치

핵심 요약

Microsoft는 2026년 6월 2일 Build 2026 발표에서 Microsoft Discovery가 정식 출시됐다고 밝혔습니다. Azure 기반의 이 플랫폼은 연구자가 가설 탐색, 실험 설계, 결과 해석까지 과학 워크플로 전반을 에이전트형 AI로 다룰 수 있게 설계됐습니다. 발표문에는 BHP가 구리 침출 해법을 수년이 아닌 수개월 단위로 찾고 있고, Syensqo는 반도체 연구개발을 가속하며, GSK는 신약 탐색 반복 속도를 높이고 있다고 사례가 제시됐습니다. 동시에 더 넓은 커뮤니티를 위한 로컬 앱 프리뷰도 함께 예고됐습니다.

배경·업계 영향

AI 도입이 문서 작성과 코딩 보조를 넘어 과학·산업 연구 프로세스의 운영 시스템으로 확장되고 있다는 점이 중요합니다. Microsoft는 오피스 생산성뿐 아니라 연구 생산성에서도 Azure 기반 에이전트 플랫폼을 기본 인프라로 만들려 하고 있습니다. 장기적으로는 기업용 AI 플랫폼 경쟁이 일반 사무업무와 연구개발 업무를 동시에 묶는 방향으로 진화할 가능성이 높습니다.

왜 중요한지: AI 플랫폼 경쟁이 백오피스 자동화를 넘어 R&D 생산성까지 직접 겨냥하기 시작했습니다.

Microsoft Blog, Microsoft Build 2026: Be yourself at work

5. NVIDIA, 일본과 국가 단위 AI 인프라 구축 발표로 공급망 우위 재확인

핵심 요약

NVIDIA는 2026년 7월 15일 일본 정부 및 산업 파트너와 함께 세계 최초의 national AI infrastructure를 출범한다고 발표했습니다. 발표에 따르면 Noetra와 협력해 13,750개의 NVIDIA Vera CPU와 27,500개의 Rubin GPU를 사용하는 AI 팩토리를 구축할 계획입니다. 회사는 이를 국가 차원의 physical AI 활용을 위한 기반으로 설명했습니다. 즉 단일 데이터센터 수주가 아니라 정부·산업이 함께 쓰는 전략 인프라 사업으로 포지셔닝한 셈입니다.

배경·업계 영향

대형 모델 경쟁이 계속될수록 결국 병목은 모델 자체보다 전력, 데이터센터, GPU 공급, 국가 차원의 투자 집행으로 이동합니다. NVIDIA는 이런 전환에서 칩 공급사를 넘어 국가 AI 인프라 설계 파트너로 역할을 넓히고 있습니다. 이는 향후 AI 산업이 소프트웨어 기업 중심 경쟁에서 반도체·전력·국가 정책이 얽힌 중장기 설비 경쟁으로 더 깊게 들어간다는 뜻이기도 합니다.

왜 중요한지: AI의 다음 승부는 모델 성능만이 아니라 누가 국가 단위 계산 인프라를 먼저 확보하느냐에 달려 있습니다.
