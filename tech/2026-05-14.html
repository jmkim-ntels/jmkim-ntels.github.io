1. Meta, WhatsApp에 ‘Incognito Chat with Meta AI’ 도입

핵심 요약

Meta는 5월 13일 WhatsApp과 Meta AI 앱에 ‘Incognito Chat with Meta AI’를 도입한다고 발표했습니다. 회사 설명에 따르면 이 기능은 WhatsApp의 Private Processing 기술 위에서 동작하며, Meta조차 대화 내용을 볼 수 없는 완전 비공개 AI 대화를 목표로 합니다. 대화는 기본적으로 저장되지 않고, 임시 세션처럼 사라지는 방식으로 설계됐습니다. Meta는 향후 WhatsApp 일반 대화 맥락을 활용하는 Side Chat도 같은 프라이버시 구조 위에서 제공할 예정이라고 밝혔습니다.

배경·업계 영향

AI 사용이 개인적이고 민감한 질문으로 확장될수록 프라이버시 설계는 단순 부가 기능이 아니라 채택 조건이 됩니다. Meta는 이번 발표로 ‘AI를 더 많이 붙인다’보다 ‘AI를 얼마나 안심하고 쓰게 하느냐’로 경쟁 축을 이동시키려는 모습입니다. 메신저 기반 AI를 운영하는 다른 사업자들도 보안 아키텍처와 데이터 처리 방식을 더 구체적으로 설명해야 하는 압박을 받을 가능성이 큽니다.

왜 중요한지: 메신저 AI의 다음 승부처는 성능뿐 아니라 “누가 이 대화를 볼 수 있느냐”에 대한 신뢰입니다.

2. Anthropic, ‘Claude for Small Business’ 공개

핵심 요약

Anthropic은 5월 13일 소규모 사업자를 위한 패키지형 제품 ‘Claude for Small Business’를 발표했습니다. 이 제품은 QuickBooks, PayPal, HubSpot, Canva, Docusign, Google Workspace, Microsoft 365 같은 도구에 Claude를 연결해 급여 계획, 월마감, 인보이스 추적, 마케팅 캠페인 준비 같은 반복 업무를 처리하도록 설계됐습니다. Anthropic은 기본 제공 커넥터와 함께 15개의 ready-to-run 워크플로와 15개의 스킬을 제공한다고 설명했습니다. 또한 모든 작업은 사용자가 승인한 뒤 실행되도록 하며, 기존 권한 체계와 데이터 보안 원칙을 유지한다고 강조했습니다.

배경·업계 영향

그동안 중소기업용 AI는 범용 챗봇 체험에 머무는 경우가 많았는데, 이번에는 실제 업무 소프트웨어 안으로 들어가는 ‘패키지형 자동화’에 더 가깝습니다. 이는 엔터프라이즈 AI 시장에서 검증된 커넥터 전략이 SMB 시장으로 내려오기 시작했다는 신호이기도 합니다. 앞으로는 모델 성능보다 회계·영업·운영 도구를 얼마나 깊게 연결하느냐가 중소기업 AI 도입 속도를 좌우할 가능성이 큽니다.

왜 중요한지: SMB 시장에서 AI의 진짜 경쟁은 멋진 데모보다 밤늦게 남는 잡무를 실제로 줄여주느냐입니다.

3. OpenAI, API용 실시간 음성 모델 3종 발표

핵심 요약

OpenAI는 5월 7일 API용 신규 음성 모델로 GPT‑Realtime‑2, GPT‑Realtime‑Translate, GPT‑Realtime‑Whisper를 공개했습니다. GPT‑Realtime‑2는 GPT‑5급 추론을 음성 대화에 접목해 툴 호출, 대화 맥락 유지, 중간 수정 대응을 강화한 것이 핵심입니다. 번역 모델은 70개 이상 입력 언어와 13개 출력 언어를 지원하고, Whisper 기반 스트리밍 전사는 실시간 자막·회의 기록·콜센터 후속처리 같은 용도를 겨냥합니다. OpenAI는 컨텍스트 윈도를 32K에서 128K로 늘리고, reasoning level을 단계별로 조절할 수 있게 했다고 설명했습니다.

배경·업계 영향

이 발표는 음성이 더 이상 단순한 입출력 채널이 아니라, 에이전트가 일을 수행하는 핵심 인터페이스로 올라가고 있음을 보여줍니다. 특히 번역과 전사, 툴 호출이 한 스택 안에서 정리되면 고객지원·여행·현장 업무 같은 분야에서 음성 자동화 도입이 빨라질 수 있습니다. 동시에 음성 AI 시장도 결국 정확도만이 아니라 지연시간, 제어 가능성, 안전장치 경쟁으로 재편될 가능성이 큽니다.

왜 중요한지: 실시간 음성 AI가 똑똑해질수록 챗봇은 화면 안이 아니라 전화·회의·현장 업무로 확장됩니다.

4. Google Cloud, Gemini Enterprise Agent Platform으로 Vertex AI를 에이전트 중심으로 재편

핵심 요약

Google Cloud는 4월 23일 Gemini Enterprise Agent Platform을 발표하며 Vertex AI의 기능을 에이전트 구축·운영·거버넌스 중심으로 묶겠다고 밝혔습니다. 회사 설명에 따르면 이 플랫폼은 Agent Studio, ADK, Agent Runtime, Memory Bank, Agent Registry, Agent Gateway, Agent Observability 같은 구성요소를 한데 통합합니다. 또한 Model Garden을 통해 200개 이상 모델에 접근할 수 있고, Gemini 계열뿐 아니라 Anthropic 등 서드파티 모델도 활용할 수 있다고 설명했습니다. Google은 앞으로 Vertex AI의 로드맵 진화가 별도 서비스가 아니라 Agent Platform을 통해 제공될 것이라고 못 박았습니다.

배경·업계 영향

이건 단순 제품 추가가 아니라 Google Cloud의 AI 스토리텔링이 ‘모델 제공자’에서 ‘기업용 에이전트 운영체제 제공자’로 옮겨간다는 선언에 가깝습니다. 기업 입장에서는 모델 선택보다 장기 상태 유지, 보안, 감사, 배포 자동화가 더 중요한 구매 포인트가 되기 시작했습니다. 경쟁 클라우드도 에이전트 플랫폼 메시지를 더 제품화된 운영 도구로 구체화해야 할 가능성이 큽니다.

왜 중요한지: 기업 AI의 실전 경쟁은 이제 좋은 모델 하나보다 에이전트를 안전하게 굴리는 전체 스택에서 벌어집니다.

5. AWS, ‘What’s Next with AWS 2026’에서 Amazon Quick과 OpenAI-on-Bedrock 확대 발표

핵심 요약

AWS는 4월 28일 ‘What’s Next with AWS 2026’ 발표를 통해 Amazon Quick 데스크톱 앱, 무료·플러스 요금제, 비주얼 자산 생성, 추가 앱 연동 기능을 공개했습니다. 동시에 Amazon Connect를 공급망·채용·고객경험·헬스케어용 네 가지 agentic AI 솔루션으로 확장한다고 밝혔습니다. 더불어 OpenAI와의 협력을 확대해 GPT-5.5·GPT-5.4 계열 모델, Codex, Bedrock Managed Agents powered by OpenAI를 Amazon Bedrock에 제한적 프리뷰로 들여온다고 발표했습니다. AWS의 메시지는 자체 서비스와 외부 프런티어 모델을 모두 흡수하는 ‘운영 허브’ 역할에 가깝습니다.

배경·업계 영향

AWS는 순수 모델 경쟁보다 고객이 이미 쓰는 인프라와 업무 시스템 위에 에이전트를 얹는 전략을 강화하고 있습니다. 특히 OpenAI 모델을 Bedrock 안으로 끌어들인 것은 멀티모델 선택권이 이제 클라우드 경쟁력의 핵심이 됐다는 점을 보여줍니다. 앞으로 클라우드 사업자들은 자체 모델 유무와 별개로 누가 더 많은 프런티어 모델과 거버넌스를 한 화면에서 제공하느냐를 두고 다툴 가능성이 큽니다.

왜 중요한지: 클라우드 전쟁은 “우리 모델을 써라”보다 “원하는 모델을 우리 운영체계 안에서 써라”로 바뀌고 있습니다.

6. SAP와 NVIDIA, 기업용 AI 에이전트 신뢰 계층 공동 강화

핵심 요약

NVIDIA는 5월 12일 SAP Sapphire 발표를 계기로 SAP와의 협업 확대 내용을 공개했습니다. 핵심은 NVIDIA OpenShell을 SAP Business AI Platform에 통합해, 자율형 AI 에이전트의 실행 환경에 격리·정책 집행·감사 추적 기능을 넣는 것입니다. SAP는 Joule Studio에서 만드는 커스텀 에이전트까지 이 런타임 보안 계층을 활용하게 되며, NVIDIA NemoClaw도 Joule Studio에서 바로 쓸 수 있게 할 계획이라고 밝혔습니다. 양사는 애플리케이션 레이어에서 신뢰할 수 있는 agentic AI 운영 기반을 함께 만들겠다는 메시지를 분명히 했습니다.

배경·업계 영향

에이전트가 ERP·재무·공급망 시스템에 직접 손대기 시작하면 보안은 모델 바깥 문제가 아니라 제품 핵심 기능이 됩니다. 이번 협업은 대기업 소프트웨어 시장에서 에이전트 런타임 보안이 별도 옵션이 아니라 기본 인프라로 올라서고 있음을 보여줍니다. 다른 엔터프라이즈 SaaS 업체들도 권한, 격리, 감사 레이어를 더 전면에 내세울 가능성이 큽니다.

왜 중요한지: 기업이 AI 에이전트를 실제 업무에 풀기 위해선 똑똑함보다 먼저 ‘통제 가능성’이 확보돼야 합니다.
