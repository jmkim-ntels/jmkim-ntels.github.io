  • 개인 재무, 메신저, 소상공인 운영, 개발 자동화처럼 구체적 현업 영역으로 AI가 더 깊게 파고들고 있습니다.

1. OpenAI, ChatGPT에 개인 금융 전용 경험 프리뷰 공개

핵심 요약

OpenAI는 5월 15일 미국 내 ChatGPT Pro 사용자를 대상으로 개인 금융 경험 프리뷰를 시작했습니다. 사용자는 Plaid를 통해 1만2천 개 이상 금융기관 계정을 연결하고, 지출·구독·포트폴리오·예정 결제 현황을 한 화면에서 볼 수 있습니다. ChatGPT는 연결된 금융 데이터와 사용자가 제공한 목표 정보를 바탕으로 예산, 소비 패턴, 시나리오 비교 같은 질문에 더 맥락 있는 답변을 제공하도록 설계됐습니다. OpenAI는 다만 이 기능이 전문 재무 자문을 대체하는 것은 아니라고 선을 그었습니다.

배경·업계 영향

이 발표는 생성형 AI가 검색 보조나 문서 작성 단계를 넘어, 민감한 개인 데이터가 얽힌 실제 생활 의사결정 영역으로 확장되고 있음을 보여줍니다. 동시에 금융 서비스 AI의 승부처가 단순 챗봇 응답이 아니라 계정 연결, 데이터 통합, 신뢰 설계로 이동하고 있다는 점도 분명해졌습니다. 핀테크와 은행권은 자체 앱 경험과 외부 AI 인터페이스 사이의 주도권 경쟁을 더 강하게 의식하게 될 가능성이 큽니다.

왜 중요한지: AI가 ‘조언’에서 ‘개인 재무 맥락을 읽는 인터페이스’로 한 단계 더 들어왔습니다.

2. OpenAI, Codex를 모바일 앱으로 확장해 장기 실행형 작업 관리 강화

핵심 요약

OpenAI는 5월 14일 Codex를 ChatGPT 모바일 앱 프리뷰로 확장했다고 발표했습니다. 이제 사용자는 휴대폰에서 진행 중인 Codex 스레드를 확인하고, 승인·방향 수정·새 작업 시작·모델 변경까지 할 수 있습니다. OpenAI에 따르면 Codex는 이미 주당 400만 명 이상이 사용 중이며, 모바일에서는 원격 환경의 화면·터미널 출력·테스트 결과·diff까지 실시간으로 확인할 수 있습니다. 함께 공개된 업데이트로 Remote SSH 일반 가용화, 엔터프라이즈용 프로그램형 액세스 토큰, Hooks 일반 가용화, HIPAA 환경 지원도 포함됐습니다.

배경·업계 영향

AI 코딩 도구가 단순 자동완성에서 장시간 실행형 에이전트로 진화하면서, 사용자는 데스크톱 앞이 아니어도 중간 승인과 개입을 할 수 있어야 합니다. 이번 발표는 AI 코딩 경쟁의 중심이 모델 성능뿐 아니라 세션 연속성, 원격 운영성, 엔터프라이즈 통제로 넓어졌음을 보여줍니다. 앞으로 코딩 에이전트 시장에서는 “얼마나 오래 일할 수 있나” 못지않게 “사람이 얼마나 자연스럽게 개입할 수 있나”가 중요한 비교 기준이 될 가능성이 큽니다.

왜 중요한지: 코딩 AI가 보조 도구를 넘어 ‘항상 돌아가는 작업자’로 자리잡으려면 모바일 승인 경험이 핵심입니다.

3. Anthropic, ‘Claude for Small Business’로 소상공인용 업무 자동화 패키지 출시

핵심 요약

Anthropic은 5월 13일 Claude for Small Business를 공개했습니다. 이 패키지는 QuickBooks, PayPal, HubSpot, Canva, Docusign, Google Workspace, Microsoft 365 같은 도구와 연결돼 급여 계획, 월말 마감, 청구 추적, 마케팅 캠페인 준비 같은 일을 Claude 안에서 처리하도록 설계됐습니다. 회사는 15개의 즉시 실행형 에이전트 워크플로와 15개의 스킬을 함께 제공한다고 설명했습니다. 중요한 점은 Claude가 일을 진행하되, 실제 송금·발송·게시 전에는 사람이 승인하도록 설계했다는 점입니다.

배경·업계 영향

대기업용 AI 플랫폼 경쟁이 치열한 가운데 Anthropic은 소규모 사업 운영이라는 더 구체적이고 반복적인 업무 시장을 정면으로 겨냥했습니다. 이는 AI 도입 장벽이 높은 중소 사업자에게 “도구를 따로 배우는 AI”가 아니라 “이미 쓰는 SaaS 안으로 들어오는 AI”를 제시한 움직임입니다. 향후 SMB 소프트웨어 시장에서는 회계·CRM·디자인·전자서명 같은 업무 SaaS들이 AI 연결성과 자동화 패키지를 더 적극적으로 번들링할 가능성이 큽니다.

왜 중요한지: AI 수익화의 다음 전장은 대기업 PoC보다, 매일 반복되는 소상공인 백오피스 업무일 수 있습니다.

4. Meta, WhatsApp에 ‘완전 비공개’ Incognito Chat with Meta AI 도입

핵심 요약

Meta는 5월 13일 WhatsApp과 Meta AI 앱에 Incognito Chat with Meta AI를 도입한다고 발표했습니다. 이 기능은 WhatsApp의 Private Processing 기술 기반으로 동작하며, Meta조차 대화 내용을 볼 수 없도록 설계했다고 설명했습니다. 대화는 임시 세션처럼 처리되고 기본적으로 저장되지 않으며, 메시지도 사라지는 방식입니다. Meta는 건강, 대출, 진로처럼 민감한 질문을 AI에게 더 안심하고 물을 수 있는 환경을 만들겠다는 취지라고 밝혔습니다.

배경·업계 영향

메신저 AI 경쟁이 격화될수록 사용자는 답변 품질만큼이나 누가 대화를 볼 수 있는지에 민감해집니다. Meta는 이번 발표로 AI 기능 확장뿐 아니라 프라이버시 아키텍처 자체를 제품 차별점으로 전면에 세웠습니다. 다른 메신저·AI 플랫폼도 저장 정책, 처리 위치, 운영자 가시성에 대해 더 구체적인 설명 압박을 받을 가능성이 큽니다.

왜 중요한지: 민감한 AI 대화 시장에서는 성능보다 먼저 ‘안심하고 말할 수 있느냐’가 채택을 좌우할 수 있습니다.

Meta Newsroom, Introducing a Completely Private Way to Chat With AI Meta AI, Private Processing technical whitepaper

5. Google Cloud, Gemini Enterprise Agent Platform으로 기업용 에이전트 운영 스택 강화

핵심 요약

Google Cloud는 Gemini Enterprise Agent Platform을 통해 Vertex AI를 에이전트 구축·확장·거버넌스·최적화 중심 플랫폼으로 확장했다고 밝혔습니다. 발표문에 따르면 이 플랫폼은 모델 선택, 모델 빌드, 에이전트 빌드 기능에 더해 통합, DevOps, 오케스트레이션, 보안 기능을 함께 묶습니다. Google은 여러 시스템을 넘나들며 동작하는 에이전트를 신뢰 가능하게 운영하려면 더 강한 보안과 거버넌스 기반이 필요하다고 강조했습니다. 메시지의 핵심은 ‘좋은 모델’보다 ‘안전하게 굴러가는 에이전트 시스템’에 무게를 옮긴 점입니다.

배경·업계 영향

기업 고객은 이제 모델 벤치마크보다 배포, 관찰 가능성, 승인 흐름, 보안 통제를 더 현실적인 구매 기준으로 보기 시작했습니다. Google Cloud의 이번 포지셔닝은 클라우드 AI 경쟁이 프런티어 모델 제공 경쟁에서 에이전트 운영체계 경쟁으로 이동하고 있음을 상징합니다. AWS, Microsoft, Salesforce 등도 유사하게 에이전트 거버넌스와 운영 레이어를 핵심 제품 메시지로 더 강하게 밀 가능성이 큽니다.

왜 중요한지: 기업 AI의 실전 승부는 모델 한 방이 아니라, 에이전트를 안전하게 굴리는 운영 스택 전체에서 납니다.

6. GitHub, Copilot 클라우드 에이전트 작업 시작용 REST API 공개 프리뷰

핵심 요약

GitHub는 5월 13일 Copilot Business·Enterprise 사용자가 REST API로 Copilot cloud agent 작업을 시작할 수 있는 Agent tasks API 공개 프리뷰를 발표했습니다. Copilot cloud agent는 자체 개발 환경에서 백그라운드로 코드 변경을 만들고 검증한 뒤, 풀 리퀘스트까지 열 수 있는 구조입니다. GitHub는 새 API를 통해 대규모 리팩터링, 저장소 초기 설정, 주간 릴리스 준비 같은 작업을 사내 자동화에 쉽게 엮을 수 있다고 설명했습니다. 시작한 작업의 진행 상황도 API로 추적할 수 있으며, 현재는 PAT와 OAuth 토큰 인증을 지원합니다.

배경·업계 영향

이 발표는 코딩 에이전트가 IDE 내부 기능을 넘어, 기업 개발 플랫폼의 자동화 부품으로 편입되고 있음을 보여줍니다. 특히 여러 저장소에 걸친 반복 작업을 스크립트로 팬아웃할 수 있다는 점은 플랫폼 엔지니어링과 내부 개발자 포털 시장에 직접적인 영향을 줍니다. 향후 경쟁사들도 에이전트 기능을 UI가 아니라 API와 워크플로 관점에서 더 적극적으로 노출할 가능성이 큽니다.

왜 중요한지: 코딩 AI가 진짜 인프라가 되려면 채팅창이 아니라 API로도 호출되고 통제돼야 합니다.
