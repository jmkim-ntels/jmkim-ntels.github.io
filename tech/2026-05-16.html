1. Meta, WhatsApp에 완전 비공개형 ‘Incognito Chat with Meta AI’ 도입

핵심 요약

Meta는 5월 13일 WhatsApp과 Meta AI 앱에 ‘Incognito Chat with Meta AI’를 도입한다고 발표했습니다. 이 기능은 WhatsApp의 Private Processing 기술 위에서 동작하며, Meta조차 대화 내용을 읽을 수 없도록 설계됐다고 설명했습니다. 사용자가 시작한 대화는 임시 세션처럼 처리되고 기본적으로 저장되지 않으며 메시지도 사라집니다. Meta는 건강, 대출, 커리어 같은 민감한 주제에서도 더 안심하고 AI를 쓰게 만드는 것이 핵심 목적이라고 밝혔습니다.

배경·업계 영향

메신저 기반 AI는 답변 성능만으로는 차별화가 어려워지고 있어 데이터 처리 구조 자체가 경쟁 포인트가 되고 있습니다. 이번 발표는 메타가 AI 기능을 더 많이 붙이는 단계에서 나아가, 개인정보 보호 구조를 제품의 핵심 가치로 전면에 내세우기 시작했다는 신호입니다. 다른 메신저와 소셜 플랫폼도 AI 대화의 저장·열람 정책을 더 투명하게 설명해야 하는 압박을 받을 가능성이 큽니다.

왜 중요한지: 메신저 AI의 승부처가 “얼마나 똑똑한가”에서 “얼마나 안심하고 쓸 수 있는가”로 확장되고 있습니다.

2. Anthropic, ‘Claude for Small Business’로 중소사업자용 자동화 패키지 공개

핵심 요약

Anthropic은 5월 13일 ‘Claude for Small Business’를 발표하며 중소사업자용 커넥터와 즉시 실행 가능한 워크플로를 내놨습니다. QuickBooks, PayPal, HubSpot, Canva, Docusign, Google Workspace, Microsoft 365 같은 도구에 Claude를 연결해 급여 계획, 월마감, 인보이스 추적, 마케팅 준비 등을 돕는 방식입니다. 회사는 15개의 ready-to-run 워크플로와 15개의 스킬을 제공한다고 설명했습니다. 또한 실제 발송·지급·게시 전에는 사용자가 승인하도록 설계해 통제권을 유지한다고 강조했습니다.

배경·업계 영향

SMB 시장의 AI는 그동안 범용 챗봇 체험에 머무는 경우가 많았는데, 이번에는 회계·영업·운영 소프트웨어 안으로 직접 들어가는 패키지형 자동화에 더 가깝습니다. 이는 엔터프라이즈에서 검증된 커넥터 전략이 중소기업 시장으로 빠르게 내려오고 있다는 의미이기도 합니다. 앞으로 SMB용 AI 경쟁도 모델 자체보다 실제 업무 툴과 얼마나 깊게 연결되느냐가 더 중요해질 가능성이 큽니다.

왜 중요한지: 중소기업 AI의 실전 경쟁은 멋진 데모보다 야근성 잡무를 실제로 덜어주느냐에 달려 있습니다.

3. OpenAI, 실시간 음성용 신규 API 모델 3종 공개

핵심 요약

OpenAI는 5월 7일 API용 신규 오디오 모델로 GPT‑Realtime‑2, GPT‑Realtime‑Translate, GPT‑Realtime‑Whisper를 발표했습니다. GPT‑Realtime‑2는 GPT‑5급 추론을 실시간 음성 대화에 접목해 더 어려운 요청 처리, 맥락 유지, 도구 호출을 강화한 것이 핵심입니다. 번역 모델은 70개 이상 입력 언어와 13개 출력 언어를 지원하고, Whisper 기반 스트리밍 전사는 회의 기록·콜센터·실시간 자막 같은 사용처를 겨냥합니다. OpenAI는 컨텍스트 윈도를 32K에서 128K로 키워 더 긴 에이전트형 대화를 지원한다고 밝혔습니다.

배경·업계 영향

음성은 이제 단순 입출력 채널이 아니라 AI가 실제 업무를 수행하는 인터페이스로 올라오고 있습니다. 특히 번역·전사·도구 호출이 하나의 실시간 스택 안에서 정리되면 고객지원, 여행, 현장 업무 등에서 도입 장벽이 크게 낮아집니다. 음성 AI 시장도 정확도뿐 아니라 지연시간, 제어 가능성, 운영 편의성 경쟁으로 더 빠르게 재편될 가능성이 큽니다.

왜 중요한지: 실시간 음성 AI가 똑똑해질수록 챗봇은 화면 속 기능이 아니라 전화·회의·현장 업무의 인터페이스가 됩니다.

4. Google Cloud, ‘Gemini Enterprise Agent Platform’으로 Vertex AI를 에이전트 중심 플랫폼으로 확장

핵심 요약

Google Cloud는 4월 23일 Gemini Enterprise Agent Platform을 공개하며 Vertex AI를 에이전트 구축·운영·거버넌스 중심 플랫폼으로 확장한다고 발표했습니다. 회사 설명에 따르면 이 플랫폼은 모델 선택, 모델 개발, 에이전트 개발 기능에 더해 통합, DevOps, 오케스트레이션, 보안 기능을 함께 제공합니다. 또한 Model Garden을 통해 200개 이상 모델에 접근할 수 있고, Gemini 계열뿐 아니라 Anthropic 모델 등 서드파티 모델도 함께 활용할 수 있다고 밝혔습니다. Google은 앞으로 Vertex AI의 진화가 별도 서비스가 아니라 Agent Platform을 통해 이뤄진다고 못 박았습니다.

배경·업계 영향

이 발표는 Google Cloud의 AI 메시지가 “좋은 모델을 제공하는 클라우드”에서 “기업용 에이전트 운영체계”로 이동하고 있음을 보여줍니다. 기업 고객 입장에서는 이제 모델 자체보다 장기 상태 유지, 관찰 가능성, 보안, 배포 체계가 구매 기준으로 더 중요해지고 있습니다. 경쟁 클라우드도 에이전트 플랫폼 메시지를 운영 도구와 거버넌스로 더 구체화해야 할 가능성이 큽니다.

왜 중요한지: 기업 AI의 실전 경쟁은 모델 단품이 아니라 에이전트를 안전하게 굴리는 전체 스택에서 벌어집니다.

5. Microsoft와 OpenAI, 파트너십 개정으로 멀티클라우드·비독점 구조를 명확화

핵심 요약

Microsoft는 4월 27일 OpenAI와의 개정 계약을 발표하며 양사 협력의 다음 단계를 공개했습니다. 핵심은 Microsoft가 여전히 OpenAI의 주된 클라우드 파트너이지만, OpenAI가 이제 자사 제품을 다른 클라우드 고객에게도 제공할 수 있다는 점입니다. 또한 Microsoft의 OpenAI IP 라이선스는 2032년까지 유지되지만 비독점으로 바뀌었고, Microsoft가 OpenAI에 매출 배분을 지급하지 않는 구조도 명시됐습니다. 반면 OpenAI가 Microsoft에 지급하는 수익배분은 2030년까지 계속된다고 설명했습니다.

배경·업계 영향

이 개정은 초거대 AI 기업 간 협력이 “독점적 동맹”보다 “유연한 상호의존” 쪽으로 재설계되고 있음을 보여줍니다. OpenAI는 유통 채널과 인프라 선택권을 넓히고, Microsoft는 주요 지분과 Azure 우선권을 유지하는 식으로 균형을 다시 잡은 셈입니다. 다른 클라우드와 모델 기업 간 계약도 비슷한 방향으로 재조정될 가능성이 큽니다.

왜 중요한지: AI 생태계의 다음 경쟁은 기술력뿐 아니라 어떤 계약 구조가 속도와 유연성을 동시에 확보하느냐에 달려 있습니다.
