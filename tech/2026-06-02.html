1. OpenAI, Codex에 Windows 원격 제어와 GitHub Enterprise Server 연결 지원 추가

핵심 요약

OpenAI는 2026년 5월 29일자 ChatGPT Enterprise & Edu 릴리즈 노트에서 Codex의 Windows Computer Use와 원격 제어 기능을 공개했습니다. 사용자는 Windows 애플리케이션 안에서 Codex가 보고, 클릭하고, 입력하도록 할 수 있고, iOS·Android용 ChatGPT나 Mac용 Codex에서 진행 상황을 이어서 조정할 수 있습니다. 같은 업데이트에는 고객 호스팅 GitHub Enterprise Server 저장소를 위한 app template 지원도 포함됐습니다. 데모형 보조도구를 넘어, 사내 데스크톱과 내부 저장소에 직접 붙는 엔터프라이즈 에이전트 전략이 더 분명해졌습니다.

배경·업계 영향

기업 현장에서는 퍼블릭 SaaS보다 기존 Windows 업무 환경과 사내 Git 인프라를 얼마나 자연스럽게 다루느냐가 도입 속도를 좌우합니다. OpenAI가 원격 제어와 GHES 연결을 함께 밀고 있다는 점은 코딩 에이전트 경쟁이 이제 모델 품질뿐 아니라 실제 IT 환경 적응력으로 옮겨가고 있음을 보여줍니다. 특히 보안과 규정 준수 요구가 높은 조직일수록 이런 연결성이 중요한 구매 기준이 됩니다.

왜 중요한지: 에이전트가 브라우저 밖 실제 업무 PC와 내부 저장소까지 다루기 시작했다는 점이 핵심 변화입니다.

OpenAI Help Center, ChatGPT Enterprise & Edu Release Notes OpenAI Developers, Computer Use

2. Anthropic, Claude Opus 4.8과 Claude Code용 Dynamic Workflows 공개

핵심 요약

Anthropic은 2026년 5월 28일 Claude Opus 4.8을 발표하며 코딩, 에이전트 작업, 전문 지식 업무 전반에서 성능 향상을 강조했습니다. 회사는 이 모델이 Opus 4.7보다 더 신뢰할 수 있는 협업자이며, 같은 가격으로 제공된다고 밝혔습니다. 발표문에는 Opus 4.8이 코드 결함을 그냥 넘기는 비율이 이전 모델보다 크게 줄었고, Claude Code에서는 Dynamic Workflows를 통해 한 세션에서 수백 개의 병렬 서브에이전트를 돌릴 수 있다는 설명도 포함됐습니다. 초점은 단일 답변 품질보다 장기 작업을 안정적으로 끝내는 실행력에 맞춰져 있습니다.

배경·업계 영향

개발자용 에이전트는 짧은 코드 제안보다 긴 작업을 맡겼을 때 얼마나 흔들리지 않는지가 점점 더 중요해지고 있습니다. Anthropic은 이번 업데이트에서 성능 수치만이 아니라 정직성, 검증, 장기 실행 능력을 함께 내세웠습니다. 이는 코딩 모델 경쟁의 평가 기준이 "똑똑함"에서 "끝까지 맡길 수 있나"로 바뀌고 있음을 보여줍니다.

왜 중요한지: 코딩 에이전트 시장의 경쟁 포인트가 답변 품질에서 장기 자율 작업의 안정성으로 이동하고 있습니다.

3. GitHub, Copilot Memory에 삭제·범위·CLI 제어 기능을 강화

핵심 요약

GitHub는 2026년 5월 26일 Copilot Memory에 더 나은 삭제 안내, 저장소 단위 off 스위치, Copilot CLI의 `/memory` 명령을 추가했다고 발표했습니다. 이제 사용자는 메모리를 지우려 할 때 정확한 삭제 경로를 안내받고, 저장 시점에 해당 정보가 개인 선호인지 저장소 공용 사실인지 더 명확히 확인할 수 있습니다. 저장소 관리자는 리포지토리 수준에서 메모리 사용을 끌 수 있으며, CLI에서도 on/off/show 상태를 세션 간 지속되게 제어할 수 있습니다. 메모리가 편의 기능을 넘어 관리 대상 자산으로 다뤄지기 시작한 셈입니다.

배경·업계 영향

장기 메모리를 가진 에이전트는 생산성을 높이지만, 동시에 내부 코드 맥락과 사용자 선호가 축적된다는 리스크를 만듭니다. GitHub가 이번에 강조한 것은 "더 많이 기억한다"가 아니라 "누가, 어디까지, 어떻게 끌 수 있나"입니다. 앞으로 기업용 AI 도구는 메모리 성능만큼 메모리 거버넌스도 기본 요구사항이 될 가능성이 큽니다.

왜 중요한지: 에이전트 시대에는 기억 능력 자체보다 그 기억을 통제하는 관리 기능이 더 중요해지고 있습니다.

4. Google I/O 2026, Gemini 3.5와 Managed Agents로 에이전트 플랫폼 확장

핵심 요약

Google은 2026년 5월 19일 I/O 개발자 키노트에서 Gemini 3.5 시리즈와 Antigravity 2.0, Gemini API용 Managed Agents를 함께 발표했습니다. 회사는 이제 AI가 단순 보조를 넘어 워크플로 전반의 복잡한 작업을 독립적으로 처리하는 단계로 전환하고 있다고 설명했습니다. Managed Agents는 단일 API 호출로 원격 샌드박스가 포함된 완전한 에이전트를 제공해 인프라 설정 부담을 줄이도록 설계됐습니다. 여기에 Android CLI, WebMCP, AI Studio 연동까지 더해 실행 가능한 개발자 스택을 넓히고 있습니다.

배경·업계 영향

모델 API만 제공해서는 개발자 락인을 만들기 어려운 시점이라, 각 회사는 실행 환경과 도구 체인을 함께 묶고 있습니다. Google은 이번 발표에서 모델, 플랫폼, 샌드박스, 배포 흐름을 한 패키지로 연결하려는 의도를 분명히 했습니다. 이는 향후 에이전트 플랫폼 경쟁이 클라우드와 개발 도구 통합력 중심으로 전개될 가능성을 높입니다.

왜 중요한지: 모델 성능 경쟁이 플랫폼 전체 경쟁으로 번지고 있으며, Google은 그 전환을 정면으로 밀고 있습니다.

5. Samsung, 업계 최초 12단 HBM4E 샘플 출하 시작

핵심 요약

Samsung Electronics는 2026년 5월 29일 업계 최초의 12단 HBM4E 샘플을 주요 글로벌 고객사에 출하하기 시작했다고 발표했습니다. 회사는 이 제품이 안정적인 14Gbps 속도와 최대 16Gbps 확장 성능, 스택당 최대 3.6TB/s 대역폭을 제공한다고 설명했습니다. 또한 전 세대 대비 20% 이상 성능 향상과 개선된 전력·열 특성을 강조하며, 대규모 LLM과 차세대 AI 시스템 수요를 직접 겨냥했습니다. 이미 HBM4 양산 경험을 쌓은 뒤 HBM4E로 로드맵을 확장하는 흐름도 함께 제시했습니다.

배경·업계 영향

AI 인프라 확장의 실제 병목은 모델보다 메모리, 패키징, 전력 효율에서 더 자주 나타납니다. 그래서 HBM 샘플 출하와 양산 일정은 클라우드 사업자, GPU 업체, 모델 기업 모두에 중요한 신호입니다. 메모리 공급 경쟁이 다시 상위 뉴스로 올라오는 이유도 이 지점에 있습니다.

왜 중요한지: 생성형 AI의 성장 속도는 결국 HBM 같은 메모리 공급망이 얼마나 빠르게 따라오느냐에 크게 달려 있습니다.

6. NVIDIA, 2027회계연도 1분기 매출 816억 달러로 AI 인프라 수요 재확인

핵심 요약

NVIDIA는 2026년 5월 20일 발표한 2027회계연도 1분기 실적에서 매출 816억 달러, 데이터센터 매출 752억 달러를 기록했다고 밝혔습니다. 회사는 블랙웰 세대와 대형 AI 인프라 투자 확대를 핵심 배경으로 제시했고, 젠슨 황 CEO는 AI 팩토리 구축이 매우 빠르게 가속하고 있다고 평가했습니다. 이번 실적은 모델 발표보다 덜 화려해 보여도, 실제 시장 수요가 어디에 몰리는지를 가장 선명하게 보여주는 신호에 가깝습니다. 특히 데이터센터 숫자가 여전히 전체 흐름을 압도하고 있다는 점이 눈에 띕니다.

배경·업계 영향

NVIDIA 실적은 개별 반도체 기업의 숫자를 넘어 전 세계 AI 투자 속도를 보여주는 대표 지표처럼 읽힙니다. 소프트웨어 계층의 경쟁이 치열해질수록, 그 아래에서 GPU와 네트워크 장비를 얼마나 계속 살 수 있느냐가 시장 판도를 좌우합니다. 당분간 AI 산업의 체온은 모델 데모보다 인프라 매출에서 더 명확하게 드러날 가능성이 큽니다.

왜 중요한지: AI 시장의 진짜 열기는 데모보다도 실제 컴퓨트 구매 규모에서 더 선명하게 확인됩니다.

NVIDIA Investor Relations, NVIDIA Announces Financial Results for First Quarter Fiscal 2027
