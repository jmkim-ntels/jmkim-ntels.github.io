1. OpenAI, ChatGPT 메모리 최신화와 Lockdown Mode 전면 확대

핵심 요약

OpenAI는 2026년 6월 4일 ChatGPT 릴리즈 노트에서 메모리 시스템을 더 최신 상태로 유지하는 업데이트를 공개했습니다. 회사 설명에 따르면 ChatGPT는 stale하거나 서로 충돌하는 기억을 줄이고, 사용자의 선호와 진행 중인 작업 맥락을 더 잘 반영하도록 개선됐습니다. 같은 날 Lockdown Mode도 모든 로그인 사용자에게 확대됐으며, 이 기능을 켜면 웹 브라우징, 딥 리서치, 파일 다운로드 같은 네트워크 기반 기능 일부가 제한됩니다. 개인화와 보안을 함께 강화한 업데이트라는 점이 핵심입니다.

배경·업계 영향

에이전트형 AI가 실제 업무에 들어가려면 장기 기억과 데이터 유출 통제가 동시에 필요합니다. 기억을 더 잘하는 모델만으로는 부족하고, 보안 관점에서 어떤 기능을 끌 수 있는지까지 함께 제공해야 대기업과 보안 민감 조직이 채택하기 쉽습니다. OpenAI는 이번 업데이트로 생산성 기능과 통제 기능을 한 묶음으로 진화시키고 있습니다.

왜 중요한지: 오래 기억하는 AI와 안전하게 잠그는 AI가 함께 가야 기업용 신뢰가 생깁니다.

2. OpenAI 모델과 Codex, Amazon Bedrock에서 일반 제공 시작

핵심 요약

AWS는 2026년 6월 1일 GPT-5.5, GPT-5.4, Codex가 Amazon Bedrock에서 일반 제공된다고 발표했습니다. AWS 설명에 따르면 기업은 OpenAI 모델과 코딩 에이전트를 IAM, PrivateLink, KMS, CloudTrail 같은 기존 보안·거버넌스 체계 안에서 바로 사용할 수 있습니다. Codex는 앱, CLI, IDE 연동 경로에서 Bedrock 추론을 사용하며, 사용량은 기존 AWS 커밋에도 반영됩니다. OpenAI도 같은 날 AWS에서 자사 프런티어 모델과 Codex를 사용할 수 있다고 별도 발표했습니다.

배경·업계 영향

엔터프라이즈 AI 시장에서는 성능만큼이나 기존 클라우드 운영 절차에 얼마나 자연스럽게 들어오는지가 중요합니다. 이번 발표는 OpenAI가 직접 서비스 채널을 넘어서, AWS를 이미 표준으로 쓰는 조직들 안으로 더 깊게 들어갔다는 의미가 있습니다. 모델 경쟁이 클라우드 유통과 운영 체계 경쟁으로 재편되고 있다는 흐름을 잘 보여줍니다.

왜 중요한지: 기업은 더 강한 모델보다도, 이미 신뢰하는 클라우드 통제면 안에서 돌아가는 모델을 먼저 선택합니다.

3. Microsoft, Discovery를 일반 제공하며 과학·공학용 에이전트 플랫폼 상용화

핵심 요약

Microsoft는 2026년 6월 2일 Microsoft Discovery를 일반 제공한다고 발표했습니다. 공식 블로그에 따르면 Discovery는 과학·공학 연구개발 환경에서 에이전트 워크플로우를 정의하고, 지식 소스와 외부 과학 정보, 시뮬레이션과 분석 도구를 연결하며, 결과를 재현 가능하고 검토 가능하게 유지하도록 설계됐습니다. 동시에 연구자와 학생이 더 가볍게 시작할 수 있는 Microsoft Discovery 앱 프리뷰도 함께 공개됐습니다. 즉, 단순 챗 인터페이스가 아니라 연구개발 운영 플랫폼으로 포지셔닝한 발표입니다.

배경·업계 영향

AI가 사무 생산성을 넘어 신약, 소재, 반도체 같은 고부가가치 연구개발로 확장되고 있음을 보여주는 사례입니다. Microsoft는 이 시장에서 "모델 제공자"보다 "복잡한 R&D 워크플로우를 관리하는 시스템 사업자" 역할을 노리고 있습니다. 향후 빅테크 AI 경쟁은 산업별 전문 워크플로우 깊이로 더 갈릴 가능성이 큽니다.

왜 중요한지: AI 플랫폼의 다음 격전지는 문서 작성이 아니라 산업 연구개발의 반복 루프입니다.

Microsoft Azure Blog, Announcing Microsoft Discovery general availability and Microsoft Discovery app preview

4. Google, Gemini 3.5 Flash로 에이전트 실행 성능과 속도를 함께 밀어붙임

핵심 요약

Google은 2026년 5월 19일 Gemini 3.5를 발표하며 첫 모델로 3.5 Flash를 공개했습니다. 회사는 이 모델이 agentic tasks와 coding에서 frontier 성능을 목표로 하며, Gemini 앱과 Search의 AI Mode, Google AI Studio, Android Studio, Gemini Enterprise Agent Platform에 바로 들어간다고 설명했습니다. 블로그에 따르면 3.5 Flash는 장기 작업을 빠르게 수행하도록 설계됐고, Antigravity harness와 결합해 협업형 서브에이전트를 대규모로 배치할 수 있습니다. 속도와 실행력을 동시에 전면에 세운 발표입니다.

배경·업계 영향

AI 플랫폼 사업자들은 이제 "더 똑똑한 답변"보다 실제 업무를 몇 단계까지 대신 수행할 수 있는지를 강조하고 있습니다. Google은 Gemini 모델, Search, AI Studio, 엔터프라이즈 플랫폼을 하나의 agentic stack으로 묶어 락인과 생산성을 동시에 노리고 있습니다. 에이전트 런타임과 모델이 한 제품군으로 합쳐지는 흐름이 더 강해지고 있습니다.

왜 중요한지: 앞으로는 모델 성능표보다, 그 모델이 실제로 얼마나 오래 일하고 얼마나 빨리 끝내는지가 더 중요해집니다.

5. Anthropic, Project Glasswing 확대와 Opus 4.8 출시로 보안·에이전트 양축 강화

핵심 요약

Anthropic은 2026년 6월 2일 Project Glasswing를 약 150개 신규 조직으로 확대한다고 발표했고, 그 직전인 5월 28일에는 Claude Opus 4.8을 공개했습니다. Glasswing 발표에 따르면 초기 파트너들은 Claude Mythos Preview를 이용해 10,000건이 넘는 high 또는 critical 취약점을 찾아냈습니다. Opus 4.8은 코딩, agentic tasks, 전문 지식 업무에서 개선됐고, Claude Code용 dynamic workflows도 함께 소개됐습니다. Anthropic은 더 강한 모델과 더 큰 보안 운영 실험을 동시에 밀어붙이는 모습입니다.

배경·업계 영향

보안 업계에서는 AI가 공격과 방어 모두에 영향을 주는 만큼, 누가 더 빨리 방어 자동화를 운영에 넣느냐가 중요해지고 있습니다. Anthropic은 한편으로는 강한 범용 모델을 개선하고, 다른 한편으로는 실제 코드베이스 취약점 탐지와 패치 보조라는 매우 구체적인 방어 영역으로 확장하고 있습니다. 이는 프런티어 모델 기업들이 보안 제품 기업의 영역까지 일부 흡수하려는 신호로 볼 수 있습니다.

왜 중요한지: 프런티어 모델 기업들이 이제 모델 판매를 넘어 보안 운영 실무까지 직접 파고들고 있습니다.
