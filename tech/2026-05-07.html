1. OpenAI, 고위험 계정용 Advanced Account Security 공개

핵심 요약

OpenAI는 4월 30일 ChatGPT 계정용 opt-in 보안 모드인 Advanced Account Security를 공개했습니다. 이 모드를 켜면 비밀번호 기반 로그인을 끄고 패스키 또는 물리 보안키 중심으로 인증을 전환합니다. 계정 복구도 이메일·SMS 대신 백업 패스키, 보안키, 복구키 같은 더 강한 수단만 허용합니다. OpenAI는 로그인 알림, 더 짧은 세션, 활성 세션 관리 강화, 자동 학습 제외까지 함께 제공하며 같은 로그인 체계를 쓰는 Codex에도 적용된다고 밝혔습니다.

배경·업계 영향

생성형 AI 계정에는 대화 기록뿐 아니라 코드, 문서, 연결 앱, 업무 맥락이 함께 쌓이기 때문에 계정 탈취 리스크가 커지고 있습니다. OpenAI가 언론인, 연구자, 공직자 같은 고위험군을 직접 언급한 점은 AI 서비스가 민감 업무 인프라로 들어왔다는 신호입니다. 앞으로 주요 AI 서비스에서도 피싱 저항형 인증이 사실상 기본 기대치가 될 가능성이 큽니다.

왜 중요한지: AI 신뢰 경쟁은 이제 모델 성능만이 아니라 계정 보안 설계까지 포함합니다.

2. OpenAI, AWS에서 모델·Codex·Managed Agents 제한 프리뷰 시작

핵심 요약

OpenAI는 4월 28일 AWS와의 전략적 파트너십 확대를 발표하며 OpenAI 모델, Codex, Amazon Bedrock Managed Agents powered by OpenAI를 제한 프리뷰로 제공한다고 밝혔습니다. OpenAI는 GPT-5.5를 포함한 자사 모델을 Amazon Bedrock에서 제공하고, Codex는 CLI·데스크톱 앱·VS Code 확장에서 Bedrock API로 연결된다고 설명했습니다. 또한 Bedrock Managed Agents는 OpenAI 기반 에이전트를 AWS 보안·거버넌스 체계 안에서 운영할 수 있게 설계됐습니다. 핵심은 OpenAI 기능이 별도 서비스가 아니라 기존 AWS 운영 환경 속으로 직접 들어간다는 점입니다.

배경·업계 영향

대기업 고객은 최고의 모델 여부만큼 기존 클라우드 정책, 조달, 보안 통제 안에서 바로 쓸 수 있는지를 중요하게 봅니다. 이번 발표는 모델 회사와 클라우드 사업자가 경쟁하면서도 동시에 서로의 유통 채널이 되는 현재 시장 구조를 잘 보여줍니다. 앞으로 엔터프라이즈 AI 시장에서는 모델 품질과 함께 “어느 클라우드 안에서 얼마나 자연스럽게 쓸 수 있나”가 핵심 비교 기준이 될 가능성이 큽니다.

왜 중요한지: 기업 AI 시장의 승부처는 최고 성능보다 기존 클라우드 환경 안에 얼마나 부드럽게 들어오느냐로 이동 중입니다.

3. Anthropic·Amazon, Claude용 최대 5GW 신규 컴퓨트 확보

핵심 요약

Anthropic은 4월 20일 Amazon과의 새 계약을 통해 Claude 학습·배포용 최대 5기가와트 규모의 컴퓨트 용량을 확보한다고 발표했습니다. 회사는 올해 상반기 중 Trainium2 추가 용량이 들어오고, 2026년 말까지 Trainium2·Trainium3 기반으로 nearly 1GW가 가동될 예정이라고 설명했습니다. 동시에 Claude Platform을 AWS 내부에서 같은 계정, 같은 통제, 같은 청구 구조로 제공하는 방향도 예고했습니다. Amazon은 즉시 50억 달러를 투자하고 향후 최대 200억 달러 추가 투자 가능성도 열어뒀습니다.

배경·업계 영향

프런티어 모델 경쟁은 이제 알고리즘 못지않게 전력, 칩, 장기 공급계약 확보 능력의 싸움이 됐습니다. 특히 Trainium 같은 커스텀 AI 칩이 실제 상용 대규모 서비스에 얼마나 깊게 들어가느냐가 중요한 업계 신호가 되고 있습니다. 이번 발표는 클라우드와 모델 기업의 관계가 단순 공급을 넘어 사실상 장기 공동 인프라 체제로 굳어지고 있음을 보여줍니다.

왜 중요한지: 차세대 AI 경쟁의 실질 본체는 모델 발표보다 전력·칩·컴퓨트 공급망일 수 있습니다.

4. Google Cloud Next ’26, 에이전트 운영 플랫폼과 최신 TPU 전략을 전면에 배치

핵심 요약

Google은 4월 24일 Cloud Next ’26 recap에서 Gemini Enterprise Agent Platform과 최신 TPU 발표를 올해 핵심 업데이트로 재정리했습니다. 회사는 기업 관심이 “에이전트를 만들 수 있나”에서 “수천 개의 에이전트를 어떻게 관리하나”로 이동했다고 설명하며, 보안·거버넌스·확장을 묶은 운영 계층을 강조했습니다. 인프라 측면에서는 대규모 AI 워크로드를 뒷받침할 최신 TPU를 전면에 내세우며 학습과 추론 경쟁력을 함께 밀고 있습니다. 메시지는 단순 모델 발표보다 운영 가능한 엔터프라이즈 AI 스택 전체에 초점이 맞춰져 있습니다.

배경·업계 영향

기업 AI 도입은 단일 챗봇 배치보다 많은 에이전트를 안전하게 운영·감시하는 문제로 빠르게 옮겨가고 있습니다. Google의 발표는 모델, 보안, 칩, 운영 도구를 한 번에 묶어 제공하려는 하이퍼스케일러 경쟁이 한층 치열해졌다는 신호입니다. 특히 에이전트 실행 비용과 운영 복잡도를 동시에 다루려는 방향은 AI 도입의 경제성이 이제 제품 메시지 한가운데로 들어왔음을 보여줍니다.

왜 중요한지: 앞으로 기업 AI 승부는 ‘좋은 모델 하나’보다 ‘대규모 에이전트 시스템을 굴리는 전체 스택’에서 갈릴 가능성이 큽니다.

5. GitHub Copilot, 6월부터 usage-based billing으로 전환

핵심 요약

GitHub는 4월 27일 모든 Copilot 플랜이 6월 1일부터 GitHub AI Credits 기반 usage-based billing으로 전환된다고 발표했습니다. 기존 premium request 단위 대신 입력·출력·캐시 토큰 사용량에 따라 크레딧이 차감되며, 기본 구독료는 유지됩니다. 5월 초부터는 Billing Overview에서 예상 비용을 미리 볼 수 있는 preview 경험도 제공됩니다. GitHub는 Copilot이 짧은 보조 기능에서 장시간 에이전트형 코딩 세션으로 진화하면서 기존 과금 구조가 지속 가능하지 않았다고 설명했습니다.

배경·업계 영향

AI 코딩 도구가 단순 자동완성에서 자율 작업 플랫폼으로 이동할수록 공급자의 추론 비용은 급격히 커집니다. GitHub의 전환은 다른 개발자 AI 업체에도 요금 재설계 압박을 줄 가능성이 큽니다. 기업 고객 입장에서는 기능 비교 못지않게 예산 통제, 팀별 사용량 가시성, 모델별 비용 관리가 중요한 운영 항목이 됩니다.

왜 중요한지: 에이전트형 코딩 시대에는 과금 모델과 비용 통제도 제품 경쟁력의 핵심 일부입니다.

6. OpenAI, ChatGPT 기본 모델을 GPT-5.5 Instant로 업데이트

핵심 요약

OpenAI는 5월 5일 ChatGPT의 기본 모델을 GPT-5.5 Instant로 업데이트했다고 밝혔습니다. 회사는 새 모델이 더 똑똑하고 정확하며, 더 짧고 명확한 답변을 제공하고 개인화된 맥락 활용도 개선됐다고 설명했습니다. 공개된 내부 평가 기준으로는 의료·법률·금융 같은 high-stakes 프롬프트에서 GPT-5.3 Instant 대비 환각성 주장 수를 52.5% 줄였다고 제시했습니다. 동시에 이미지 업로드 분석, STEM 질의, 웹 검색 판단 능력도 개선 포인트로 제시했습니다.

배경·업계 영향

대중형 기본 모델의 품질 향상은 수억 명 규모의 사용 경험을 즉시 바꿀 수 있다는 점에서 제품 영향력이 큽니다. OpenAI가 속도보다 정확도와 응답 정제도를 강하게 전면에 둔 것은, 범용 챗봇 경쟁이 이제 체감 신뢰도와 업무 적합성 중심으로 이동하고 있음을 보여줍니다. 기본 모델 개선은 유료 고급 모델 발표만큼이나 실제 사용자 습관을 바꾸는 계기가 될 수 있습니다.

왜 중요한지: 가장 많이 쓰이는 기본 모델의 신뢰도 개선은 AI의 대중적 업무 활용 수준을 한 단계 끌어올릴 수 있습니다.
