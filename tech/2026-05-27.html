1. OpenAI와 Dell, Codex를 하이브리드·온프레미스 기업 환경으로 확장

핵심 요약

OpenAI는 5월 18일 Dell Technologies와 협력해 Codex를 하이브리드 및 온프레미스 환경으로 확장한다고 발표했습니다. OpenAI 설명에 따르면 현재 주당 400만 명 이상이 Codex를 사용하고 있으며, 활용 범위도 코드 리뷰와 테스트 커버리지를 넘어 보고서 작성, 피드백 분류, 후속 조치 정리 같은 업무형 에이전트로 넓어지고 있습니다. 이번 협력으로 Codex는 Dell AI Data Platform 및 Dell AI Factory와 연결돼 기업 내부 코드베이스, 문서, 시스템, 운영 지식에 더 가깝게 접근할 수 있게 됩니다. 즉, 퍼블릭 클라우드 바깥에 있는 기업 데이터 환경까지 에이전트 배치 경로를 넓히려는 움직임입니다.

배경·업계 영향

대기업의 생성형 AI 도입 병목은 여전히 데이터 거버넌스, 보안, 기존 시스템 연결입니다. 이런 이유로 모델 회사와 인프라 회사의 결합은 앞으로 더 자주 나타날 가능성이 큽니다. 특히 코딩 에이전트가 실제 사내 시스템에 붙으려면 성능보다 배치 통제력과 내부 맥락 접근성이 더 중요해지고 있습니다.

왜 중요한지: 엔터프라이즈 AI 시장의 승부는 모델 성능보다 “사내 환경 안에 안전하게 들어갈 수 있는가”로 옮겨가고 있습니다.

2. Google I/O 2026, Gemini 3.5 Flash와 Managed Agents 중심으로 개발자 플랫폼 재정비

핵심 요약

Google은 5월 19일 I/O 2026 개발자 하이라이트를 통해 Gemini 3.5 Flash, Antigravity 2.0, Gemini API용 Managed Agents, Google AI Studio 확장을 발표했습니다. 회사는 Gemini 3.5 Flash가 Gemini 3.1 Pro를 대부분의 벤치마크에서 앞서면서도 더 빠른 에이전트형 워크플로 엔진 역할을 한다고 설명했습니다. 또한 단일 API 호출로 격리된 Linux 환경에서 추론, 도구 사용, 코드 실행을 수행하는 Managed Agents를 공개했고, AI Studio 프로젝트를 Antigravity로 옮겨 로컬 개발과 프로덕션으로 이어 붙이는 흐름도 강조했습니다. 개발자용 AI 스택을 모델 API에서 에이전트 실행 환경까지 한 덩어리로 묶으려는 전략이 더 분명해졌습니다.

배경·업계 영향

이전까지는 개발자가 여러 도구를 직접 이어 붙여 에이전트 환경을 구성해야 했다면, 이제 대형 플랫폼이 관리형 에이전트 런타임 자체를 기본 상품으로 내세우는 단계로 넘어가고 있습니다. 이는 개발 속도를 높이는 동시에 플랫폼 종속성을 키우는 변화이기도 합니다. Google은 검색과 안드로이드, 워크스페이스, 클라우드까지 연결해 자사 생태계 안에서 에이전트 개발 흐름을 닫으려는 모습입니다.

왜 중요한지: AI 플랫폼 경쟁이 모델 API 판매에서 “에이전트 개발 운영체제” 경쟁으로 확장되고 있습니다.

3. NVIDIA, 분기 매출 816억 달러로 또 최고치 경신

핵심 요약

NVIDIA는 5월 20일 2027회계연도 1분기 실적을 발표하며 매출 816억 달러, 데이터센터 매출 752억 달러를 기록했다고 밝혔습니다. 이는 각각 전년 대비 85%, 92% 증가한 수치로, AI 인프라 수요가 여전히 매우 강하다는 점을 보여줍니다. 회사는 2분기 매출 가이던스를 910억 달러로 제시했고, 동시에 새로운 데이터센터와 엣지 컴퓨팅 중심의 보고 체계로 전환한다고 설명했습니다. Jensen Huang은 “AI factories” 확장이 빠르게 진행 중이며 agentic AI가 실제 가치를 만들기 시작했다고 평가했습니다.

배경·업계 영향

NVIDIA 실적은 단순한 반도체 회사 성과라기보다 전 세계 AI 투자 속도를 보여주는 대표 지표처럼 받아들여지고 있습니다. 특히 데이터센터 부문이 계속 압도적으로 성장하는 점은 모델 경쟁 못지않게 인프라 확보 경쟁이 더 커지고 있음을 뜻합니다. 클라우드 사업자, 엔터프라이즈 IT, 국가 단위 AI 프로젝트 모두가 여전히 GPU와 네트워킹 장비에 큰 비용을 투입하고 있다는 해석이 가능합니다.

왜 중요한지: AI 시장의 진짜 체온은 모델 데모보다 인프라 지출과 실적에서 더 선명하게 드러납니다.

4. Anthropic, SDK·MCP 툴링 기업 Stainless 인수

핵심 요약

Anthropic은 5월 18일 Stainless 인수를 발표했습니다. Anthropic 설명에 따르면 Stainless는 초창기부터 Anthropic 공식 SDK 생성을 담당해 왔고, TypeScript, Python, Go, Java 등 여러 언어용 SDK와 CLI, MCP 서버 툴링을 제공해 왔습니다. 회사는 “에이전트는 연결할 수 있는 시스템만큼만 유용하다”는 표현으로 이번 인수의 초점을 연결성과 개발자 경험 강화에 뒀습니다. 즉, 모델 성능 경쟁과 별개로 API 접근성, 툴 연결, 생태계 확장 레이어를 직접 장악하려는 행보입니다.

배경·업계 영향

에이전트 시대에는 모델이 똑똑하더라도 외부 서비스와 안정적으로 연결되지 않으면 실제 업무에 쓰기 어렵습니다. 이번 인수는 SDK 자동 생성과 MCP 서버 툴링이 더 이상 주변부 인프라가 아니라 핵심 플랫폼 자산이라는 점을 보여줍니다. 다른 AI 플랫폼도 커넥터와 개발도구 계층을 더 적극적으로 내재화할 가능성이 커졌습니다.

왜 중요한지: 앞으로의 AI 플랫폼 경쟁력은 모델뿐 아니라 “얼마나 쉽게 연결되고 배포되느냐”에서 갈립니다.

5. Microsoft와 EY, 10억 달러 규모로 기업 AI 전환 실행 조직 확대

핵심 요약

Microsoft와 EY는 5월 21일 5년에 걸쳐 10억 달러 이상을 투자하는 새 글로벌 이니셔티브를 발표했습니다. 양사는 Microsoft의 Forward Deployed Engineers와 EY의 산업별 컨설턴트가 함께 고객사 핵심 업무에 AI를 대규모 배치하는 통합 실행 모델을 제공하겠다고 밝혔습니다. 발표문에 따르면 EY는 이미 15만 명 규모의 Copilot 초기 배치에서 생산성 15% 향상을 기록했고, 이제 40만 명 이상으로 확장하고 있습니다. AI를 파일럿에서 끝내지 않고 실제 운영 체계로 전환하는 서비스형 실행 모델을 크게 키우는 발표로 볼 수 있습니다.

배경·업계 영향

많은 기업이 AI 실험은 했지만 전사 확장에는 여전히 어려움을 겪고 있습니다. 그래서 최근 경쟁 포인트는 모델 선택보다 변화관리, 데이터 통합, 보안, 업무 재설계까지 묶는 실행 조직 역량으로 이동하고 있습니다. Microsoft는 플랫폼 사업자에 머무르지 않고 대형 파트너와 함께 “AI 전환 공사” 자체를 상품화하려는 모습입니다.

왜 중요한지: 기업용 AI의 다음 매출 구간은 소프트웨어 라이선스보다 “도입을 끝까지 완수해 주는 실행 서비스”에서 커질 가능성이 높습니다.
